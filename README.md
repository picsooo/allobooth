# Allobooth — maquettes de refonte

Propositions de page d'accueil pour allobooth.ca, réalisées par Webminds Digital Solutions.

- `index.html` — page d'index vers les deux versions
- `v1/index.html` — V1 « Graphique » (illustrations CSS, sans images externes)
- `v2/index.html` — V2 « Photos » (photos Unsplash en placeholders, galerie, avis)

Sites statiques : aucun build requis. Sur Vercel, importer le repo tel quel (Framework preset : Other).
Pour deux URLs distinctes, créer deux projets sur ce repo avec Root Directory `v1` et `v2`.

Photos de la V2 : Unsplash (licence libre, usage commercial autorisé), à remplacer par les photos du client.
Avis clients de la V2 : textes fictifs, à remplacer.
